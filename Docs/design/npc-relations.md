# How NPC relations are read

## Note 47

NPC relations come from two places (checked against MES `67320b7` and the game build of 2026-10-23). The world-build commands are in the se-dev-kharak skill.
- **MES:** two NPC grids in different factions are rated from the faction-to-faction relation, the same table the turrets use (MES `67320b7`, PR #461). A pair with no value set, or a grid with no faction, counts as Enemy. An NPC rating a player uses the player's own reputation with the NPC's faction, and vanilla damage reputation lowers that for every attacker of a non-static faction. 500 and up counts as Friends and -501 and below as Enemy, as in the game (PR #460), so a player at COALITION's static 500 is Friends to MES. Target profiles still pick or skip factions by tag; they have not been retested against the table since the fix.
- **Turrets:** vanilla and WeaponCore use the faction-to-faction relation between two NPC factions, and a pair with none set counts as Enemies. Against a player they use the player's own relation with the NPC faction.
- **Targeting:** COALITION Units pick GAALSIEN by faction name (`GVK-Universal-Target-EnemyGAALSIENBeacon`, `-StrikeFighterBeacon`). Forced targets (the attacker, a turret's target, a squadmate's target) go through the override profile instead. COALITION behaviors that fight GAALSIEN set `[OverrideTargetData:GVK-Universal-Target-Override-COALITION]`, which also accepts GAALSIEN by name; every other behavior that can force a target sets `GVK-Universal-Target-Override`, which skips KOTH. Ground Units (and convoy escorts) use the `-Ground` copies of their target and override profiles, which also skip anything more than 150 m above the surface (high enough for a jumping rover): against an aircraft the Horsefly offset point sits in the sky, where a hover Unit can't follow it. Aircraft keep the full profiles: against a target more than 100 m up, every aircraft that fights on FighterPlane swaps in a close-in, level dogfight profile through its `<Name>Dogfight` group (generated by `tools/New-DogfightGroup.ps1`, e.g. `GVK-Unit-All-TriggerGroup-StrikeFighterDogfight`). Their attack runs line up above the target or hold a high minimum altitude, so against an aircraft they climb into space. The dogfight profiles line up at or just below the target's height, so two planes chasing each other don't climb together.
- **KOTH:** Neutral to every NPC faction and to players (static, `StartingReputation` 0), so its weapons with WeaponCore's Neutrals setting on fire on any grid that breaks the KOTH rules, NPC or player. In return no NPC fires on KOTH: MES target profiles skip it by tag, the override profiles above keep a grid it shot from firing back, and every non-KOTH prefab has Neutrals off.
- **Neutrals setting:** only matters for Neutral pairs (KOTH, and DERELICT with COALITION/SOBAN/KHAANEPH). It's off in every prefab except the `NKO [KOTH]` ones, so NPCs ignore Neutrals. Turning it on in an NPC prefab would make that grid fire on KOTH structures.
- **Attacker checks:** `IsAttackerHostile`, `IsAttackerNeutral` and `IsAttackerFriendly` evaluate via `EntityEvaluator.GetRelationBetweenIdentities` (master after 2.75.02, `49b3380`, PR #463, fixing #462). NPC-vs-NPC damager relations follow the faction table, so COALITION correctly evaluates GAALSIEN hits as Enemy and uses the shared `GVK-Universal-TriggerGroup-SendTargets` directly.
